# 列（空白分隔）：
#   id            输出文件名（www/<id>.zsb），仅限 [A-Za-z0-9._-]

#                 因此 content.text 烘焙的字形轮廓跨平台一致；正常只需写单个
#                 64 位十六进制。若某作品仍因平台相关因素不同，可写

# ZELA_TYPST_FONT_DIR 时复现**（build.ps1 会做）。本地裸跑 `zela-compile` 读到系统字体，
# 这几件会算出不同的值 —— 差异属预期，不得据此改本表。
