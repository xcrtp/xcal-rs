# Demo 清单（**单一真源**）：build.ps1 逐条编译 → www/<id>.xsb + www/demos.json
#
# 列（空白分隔）：
#   id            输出文件名（www/<id>.xsb），仅限 [A-Za-z0-9._-]
#   title         页面显示名（不含空白；含空白的标题也可，解析时为中间全部列）
#   script        相对 crates/app/xcal-app/scripts/ 的脚本路径
#                 （初期直接指向根目录作品，不移动它们：xtask 对拍依赖原路径）
#   payload-hash  可选；`-` 表示不校验。非 `-` 时编译后断言 payload hash，
#                 不符即 fail（保证公网 bundle 就是该平台 native 验证过的同一个）。
#
#                 **payload 含 content.text 烘焙的字形轮廓，依赖系统字体**
#                 ⇒ 同一作品的 hash 在 Windows / Linux 上必然不同。这不是构建错误。
#                 单个 64 位十六进制 = 所有平台都断言（payload 与字体无关时）；
#                 平台化写法：windows:<hash>,linux:<hash>（未列出的平台打印后跳过）。
